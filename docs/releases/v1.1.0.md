## See what every chat turn costs

Dragon IDE 1.1 adds a live usage readout next to the chat box:

- **Context:** a ring that fills as the conversation uses up the model's context window, turning amber at 90%.
- **Cache hit:** how much of your prompt the provider served from its cache. Cached input is billed at a fraction of the normal rate, so a high number means cheaper turns. Shown only for providers that cache.
- **Price:** the selected model's price per million input and output tokens. Local models show as free.

Hover any of them for the details: token counts, what this session has cost so far, and cache prices. It works with every provider OpenCode reports usage and prices for, from Anthropic and OpenAI to OpenRouter and local Ollama. In a narrow chat panel the readout moves to its own row so it never covers the model picker.

The readout's design and its cache-hit rounding are adapted from DeepSeek Harness (MIT).

## Install

Downloads for **macOS**: `DragonIDE-V1.1.0-darwin-arm64-unsigned.zip` for Apple Silicon and `DragonIDE-V1.1.0-darwin-x64-unsigned.zip` for Intel. Unzip it and move **Dragon IDE** to Applications. The app is not code-signed or notarized yet, so macOS blocks the first launch: open **System Settings › Privacy & Security** and click **Open Anyway** next to the message about Dragon IDE. `SHA256SUMS.txt` lists each download's checksum.

Local model weights are never bundled; they download only when you pick one in the app. Splash needs an Apple M3 or newer and macOS 26.4 or newer; Ollama works on other supported Macs, Intel included. Linux and Windows builds are not attached yet.
