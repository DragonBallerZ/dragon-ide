## Linux and Windows, and a fix for the model picker

Dragon IDE 1.1.1 adds downloads for **Linux** and **Windows**, signs and notarizes the Mac app, and fixes a startup bug on every platform.

## Fixed

- **The chat could start without your models.** OpenCode loads the providers your workspace configures a moment after it starts. If the chat asked for models before then, it kept OpenCode's own built-in list, and sending a message failed with "Language model unavailable". Dragon now updates the model picker whenever OpenCode reports that its providers, models or config changed. Fast Macs rarely hit it; slower machines did.
- **Windows needed a fix in the bundled OpenCode.** OpenCode looks for `AGENTS.md` files from the workspace up to your home folder. Windows paths can arrive with a lowercase drive letter (`c:\`), so OpenCode never recognized the home folder and every chat turn stopped with "Instruction initialization blocked by unavailable sources". The bundled OpenCode now compares paths the way Windows does.

## Install

**macOS:** `DragonIDE-V1.1.1-darwin-arm64.zip` for Apple Silicon and `DragonIDE-V1.1.1-darwin-x64.zip` for Intel. Unzip it and move **Dragon IDE** to Applications. The app is signed with Dragon's Apple Developer ID and notarized by Apple, so it opens without the Open Anyway step.

**Linux (x64):** `DragonIDE-V1.1.1-linux-x64.deb` for Debian and Ubuntu (`sudo apt install ./DragonIDE-V1.1.1-linux-x64.deb`) or `DragonIDE-V1.1.1-linux-x64.rpm` for Fedora and RHEL (`sudo dnf install ./DragonIDE-V1.1.1-linux-x64.rpm`). Either one adds Dragon IDE to the app menu and a `dragon-ide` command. Or unpack `DragonIDE-V1.1.1-linux-x64.tar.gz` and run `dragon-ide` in the `VSCode-linux-x64` folder.

**Windows (x64):** unzip `DragonIDE-V1.1.1-win32-x64-unsigned.zip` and run **Dragon IDE.exe** in the `VSCode-win32-x64` folder. It is not code-signed yet, so SmartScreen may stop the first launch: click **More info**, then **Run anyway**.

`SHA256SUMS.txt` lists each download's checksum. Local model weights are never bundled; they download only when you pick one in the app. Ollama works on every platform. Splash needs an Apple M3 or newer and macOS 26.4 or newer. Dragon offers a local model only when the machine has the memory for it.

## Checked before release

The agent, search, provider and usage tests, including an end-to-end run of the real OpenCode agent. Desktop tests of first-run setup and of a full chat turn with the usage readout, on the packaged app for every download: on GitHub's Linux and Windows runners, and on an Apple Silicon Mac with the Intel build under Rosetta 2. The Mac apps were tested after signing, and their signatures checked again afterward. `VALIDATION.txt` lists the commit and the runs.
