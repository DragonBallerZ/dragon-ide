Dragon IDE's usage readout adapts code from DeepSeek Harness
(https://github.com/deepseek-ai/deepseek-harness, commit 639ed015397290b3745d163aafe02ffee4aa3f84):

(packages/client/ui-chat/src/client/chat/token-format.ts)
- src/vs/workbench/contrib/dragonShared/browser/usageChips.ts and composerChips.css: the context ring
and usage pills (packages/client/ui-conversation ContextMeter, packages/client/ui-chat StatsPills)
