# Continue in the terminal

The OpenCode TUI is built in. Open it from the terminal's **+** menu (**OpenCode**), or run **Dragon: Open OpenCode TUI**.

It connects to this window's OpenCode server, so the chat and the TUI share sessions, models and credentials. To pick up a chat conversation in the TUI, run **Dragon: Continue Chat in OpenCode TUI** or use the `/tui` command in the chat. To go the other way, run **Dragon: Continue OpenCode Session in Chat** and pick the session.
