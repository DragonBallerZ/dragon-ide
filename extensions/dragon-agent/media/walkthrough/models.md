# Pick the model that runs your agent

| | |
| --- | --- |
| **Run locally** | Ollama runs the model on this machine, so it is private, free and works offline. Dragon IDE offers only models that fit your memory and call tools reliably (7B and up). |
| **API key** | Paste a key for Anthropic, OpenAI, Google, OpenRouter or another provider. OpenCode stores it, and Dragon IDE keeps no copy. |
| **Sign in** | Use a subscription you already have, where the provider supports it. |

Use **Connect AI** on the home screen or status bar whenever you’re ready. You can also run **Dragon: Connect AI** from the command palette. After setup, the button becomes **Manage AI**; the chat model picker and **Dragon: Choose Model** remain available.


**Local AI setup** detects memory, chip, OS and free storage. Choose Ollama or Splash, review the Hugging Face model and download size, then install a model that fits. Splash is included on Apple silicon and needs an M3 or newer Mac with macOS 26.4+.

[Set Up Local AI](command:dragon.localAI.setup)
